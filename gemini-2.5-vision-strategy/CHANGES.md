# 変更履歴

## v4.0.0 (2025-11-04) - Gemini 2.5 ビジョン戦略対応版

### 🚀 主要アップデート

#### 1. Gemini 2.5 Flash への完全移行
- **モデル変更**: `gemini-2.0-flash-exp` → `gemini-2.5-flash-preview-04-17`
- **APIバージョン**: `v1beta` を維持
- **パラメータ最適化**:
  - `topP`: 0.8 → 0.85（Gemini 2.5推奨値）
  - `temperature`: 0.7（維持）
  - `maxOutputTokens`: 8192（維持）

#### 2. 企業分析項目の大幅拡張

**新規追加された列（事前ワークシート）**:
- `AsPhoto` / `AsPhototext`: **解決すると良くなる「課題」**
- `PrPhoto` / `PrPhototext`: **解決しなければならない「問題」**
- `VsPhoto` / `VsPhototext`: **3年後のありたい姿（ビジョン）**

**従来からの列**:
- `StPhoto` / `StPhototext`: 企業の強み
- `WkPhoto` / `WkPhototext`: 企業の弱み

**合計12列の包括的な企業分析が可能に**

#### 3. 戦略的優先順位付き分析の実装

**分析の優先順序**:
1. **問題（PrPhototext）**: 最優先で解決すべき事項
2. **課題（AsPhototext）**: 改善すべき事項
3. **ビジョン（VsPhototext）**: 3年後の目標達成への貢献

**プロンプトの改善**:
```
分析時の優先順位：
1. 「解決しなければならない問題」を最優先で解決
2. 「解決すると良くなる課題」を次に改善
3. 「3年後のありたい姿（ビジョン）」に向けた戦略的貢献を明確化
4. 企業の「強み」を最大限活用し、「弱み」を補完する施策を提案
```

### 📊 出力フォーマットの強化

#### 1. ミッション概要の拡張

```
🌱 改善する課題: [次に改善する課題]
```

- `🔴 解決する問題`: 該当フェーズで解決する問題
- `🟡 改善する課題`: 該当フェーズで改善する課題

```

  📊 [指標1名]: [現状]→[目標値]

🟡 課題改善指標:
```

#### 6. 期待効果の短期・長期分離
- **短期効果**: 問題解決・課題改善
- **長期効果**: 3年後ビジョン達成への貢献

### 🚧 既知の制限事項

1. **APIクォータ**
   - Gemini 2.5は新しいモデルのため、クォータ制限に注意
   - レート制限エラー時は待機時間を調整

2. **列の必須性**
   - `Group`, `StPhototext`, `WkPhototext` は必須
   - 課題・問題・ビジョンは任意だが、設定を推奨

3. **出力トークン数**
   - 8192トークンで制限
   - 超過する場合は出力が途中で切れる可能性
