# Gemini ビジョン戦略型プロジェクト企画自動生成 v4.0.0

## 概要

このスクリプトは、Google Apps Scriptで動作する、**Gemini最新版**を活用したプロジェクト企画自動生成システムです。

社員のアイディアと企業の戦略情報（強み・弱み・課題・問題・3年後のビジョン）を統合し、実行可能なプロジェクト企画書を自動生成します。

## 主な特徴

### 🆕 v4.0.0の新機能

1. **Gemini最新モデル対応**
   - 最新のGemini実験的モデル (gemini-exp-1206) を使用
   - より高度な推論能力と長文生成能力
   - 他のモデルへの切り替えも簡単に可能

2. **拡張された企業分析項目**
   - **解決すると良くなる「課題」** (AsPhototext列)
   - **解決しなければならない「問題」** (PrPhototext列)
   - **3年後のありたい姿（ビジョン）** (VsPhototext列)
   - 従来の「強み」「弱み」に加えて、より戦略的な分析が可能に

3. **優先順位付き分析**
   - 問題（最優先）→ 課題 → ビジョン達成 の順で分析
   - 戦略的な優先度に基づいたプロジェクト提案

4. **ビジョン指向の企画書**
   - 3年後のビジョンへの貢献度を明確化
   - 短期・長期の効果を分けて提示

## 必要な準備

### 1. Google Spreadsheetの準備

#### 「事前ワーク」シート
以下の列を含むシートを作成してください：

| 列名 | 説明 |
|------|------|
| ID | 識別子 |
| Group | グループ名（企業名など） |
| 業種・業態 | 企業の業種・業態 |
| StPhoto | 強みの写真（オプション） |
| StPhototext | 企業の強み（テキスト） |
| WkPhoto | 弱みの写真（オプション） |
| WkPhototext | 企業の弱み（テキスト） |
| **AsPhoto** | 課題の写真（オプション） |
| **AsPhototext** | **解決すると良くなる「課題」** |
| **PrPhoto** | 問題の写真（オプション） |
| **PrPhototext** | **解決しなければならない「問題」** |
| **VsPhoto** | ビジョンの写真（オプション） |
| **VsPhototext** | **3年後のありたい姿（ビジョン）** |

#### 「Selections」シート
社員のアイディアを記録するシート：

| 列名 | 説明 |
|------|------|
| SelectionID | 選択ID |
| PlayerName | 社員ID |
| Group | グループ名 |
| CardName | 制約条件（期間・予算など） |
| Response | アイディア詳細 |
| CreatedAt | 作成日時 |
| Title | 生成されたタイトル |
| Analysis | 翻訳キー分析結果 |
| ProjectPlan | プロジェクト計画（詳細） |
| ProjectPlanSummary | プロジェクト計画（サマリー） |

#### 「Players」シート
社員情報を管理するシート：

| 列名 | 説明 |
|------|------|
| PlayerID | 社員ID |
| PlayerName | 社員名 |

### 2. Google AI Studio APIキーの取得

1. [Google AI Studio](https://makersuite.google.com/app/apikey) にアクセス
2. APIキーを発行
3. スクリプトのメニューから「APIキーを設定」を実行し、キーを登録

### 3. スクリプトのインストール

1. Google Spreadsheetを開く
2. 「拡張機能」→「Apps Script」を選択
3. `project-planner-gemini-2.5.gs` の内容をコピー&ペースト
4. 保存して、スプレッドシートに戻る

## 使い方

### メニュー構成

スプレッドシートを開くと、「🤖 AIプロジェクト企画 v4.0 (Gemini 2.5)」というメニューが表示されます。

#### 1. APIキーを設定
初回のみ実行。Google AI Studio で取得したAPIキーを設定します。

#### 2. 選択行の企画案を作成
「Selections」シートで特定の行を選択して実行すると、その行のアイディアに対する企画案を生成します。

#### 3. 未処理の企画案をすべて作成
「Title」列が空の行をすべて処理し、企画案を一括生成します。

#### 4. 📄 企画案をGoogleドキュメントで出力
生成された企画案をグループごとにGoogleドキュメントとして出力します。
- プロジェクト詳細
- プロジェクトサマリーカード（ワークショップ用）

#### 5. 🔧 モデル情報を確認
使用中のGeminiモデル名とAPIキーの設定状態を確認します。

### 1. 翻訳キー分析結果
- アイディアの戦略的位置づけ

- **問題・課題への貢献度**
- **ビジョンへの戦略整合性**

### 2. ゲーミフィケーション実行計画サマリー
- 🎯 ミッション概要
  - 解決する問題
  - 改善する課題
  - **ビジョンへの貢献**
- 📊 現状分析ダッシュボード
  - 課題・問題レベル（優先度付き）
  - **3年後のビジョン達成への貢献**
- ⚔️ 推奨チーム編成
- 🗺️ 攻略マップ（実行計画）
- 📈 主要成功指標（問題解決・課題改善・ビジョン貢献）
- 💰 投資配分
- 🎯 期待効果（短期・長期）
- ⚠️ リスク管理
- 🚀 今すぐ開始アクション

### 3. 詳細版プロジェクト計画
- プロジェクト概要
- 現状課題と戦略的機会
- 実行計画（フェーズ別）
- 投資計画・ROI予測
- 成功指標・KPI（3階層）
  - 問題解決指標
  - 課題改善指標
  - **ビジョン貢献指標**
- 実行体制・リソース
- リスク管理・対策
- **戦略的インパクト（ビジョン達成への貢献度）**

## 技術仕様

### モデル設定
```javascript
const MODEL_NAME  = 'gemini-2.0-flash-exp';  // Gemini 2.0 Flash（安定版・推奨）
const API_VERSION = 'v1beta';
```

**利用可能な代替モデル:**
- `gemini-2.0-flash-exp` - Gemini 2.0 Flash（**安定版・推奨**）
- `gemini-exp-1206` - 最新の実験的モデル（レート制限が厳しい）
- `gemini-2.0-flash-thinking-exp-1219` - 思考プロセス表示版
- `gemini-1.5-flash-latest` - Gemini 1.5 Flash
- `gemini-1.5-pro-latest` - Gemini 1.5 Pro（高精度版）

### 生成パラメータ
```javascript
temperature: 0.7      // 創造性と一貫性のバランス
topP: 0.85           // 推奨値
topK: 40             // 語彙選択の幅
maxOutputTokens: 8192 // 長文出力対応
```

### レート制限対策
- **自動リトライ機能**: レート制限エラー（429）時に自動的に3回までリトライ
- **指数バックオフ**: 3秒 → 6秒 → 12秒と待機時間を延長
- **連続実行時の待機**: 複数行処理時は3秒間隔で実行

## 注意事項

1. **APIキーの管理**
   - APIキーは機密情報です。第三者と共有しないでください
   - Google AI StudioでAPIキーの使用量を定期的に確認してください

2. **レート制限**
   - 連続実行時は1.5秒の待機時間を設定しています
   - 大量のデータを処理する場合は、API使用量に注意してください

3. **データの準備**
   - 「事前ワーク」シートの全12列を正しく設定してください
   - 課題・問題・ビジョンは任意ですが、設定するとより戦略的な提案が得られます

4. **出力の確認**
   - 生成された企画書は必ず人間が確認・修正してください
   - AIが生成した内容は参考として活用してください

## トラブルシューティング

### APIエラーが発生する場合
1. APIキーが正しく設定されているか確認
2. Google AI Studioでクォータを確認
3. モデル名が正しいか確認（gemini-2.0-flash-exp）
4. モデルが利用できない場合は、代替モデルに切り替え
   - スクリプト内の `MODEL_NAME` を変更
   - 例: `const MODEL_NAME = 'gemini-1.5-flash-latest';`

### レート制限エラー（429）が発生する場合
1. **自動リトライ**: スクリプトは自動的に3回までリトライします
2. **待機時間**: 3秒 → 6秒 → 12秒と指数的に待機時間が延長されます
3. **それでもエラーが続く場合**:
   - 一時的にAPI使用を停止し、数分待ってから再試行
   - Google AI Studioでクォータ状況を確認
   - 1日の使用量制限に達している可能性があります

### 企画書が生成されない場合
1. 「事前ワーク」シートのGroup名が一致しているか確認
2. 必須列（Group, StPhototext, WkPhototext）にデータが入力されているか確認
3. Logger.log の出力を確認（Apps Scriptエディタの「実行ログ」）

### 出力が途中で切れる場合
- maxOutputTokens を調整（デフォルト: 8192）
- プロンプトの長さを確認
