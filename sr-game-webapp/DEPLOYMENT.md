# デプロイメントガイド

社労士ゲームWEBアプリの本番環境へのデプロイ手順

## 📋 事前準備

- Googleアカウント
- Google Apps Scriptへのアクセス権限
- Webホスティングサービス（GitHub Pages、Netlify、Vercelなど）

## 🚀 ステップ1: Google Apps Script のセットアップ

### 1-1. プロジェクトの作成

1. https://script.google.com にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「社労士ゲーム - バックエンド」に変更

### 1-2. コードのコピー

1. `backend/Code.gs` の全内容をコピー
2. Google Apps Script エディタに貼り付け
3. 保存（Ctrl+S または Cmd+S）

### 1-3. スプレッドシートの初期化

1. エディタ上部の関数選択で `initializeSpreadsheet` を選択
2. 実行ボタン（▶）をクリック
3. 初回実行時：
   - 「承認が必要です」というダイアログが表示されます
   - 「権限を確認」をクリック
   - Googleアカウントを選択
   - 「詳細」をクリック → 「（安全ではないページ）に移動」をクリック
   - 「許可」をクリック
4. 実行ログを確認：
   - 「実行ログ」タブをクリック
   - スプレッドシートのURLが表示されます
   - **このURLを保存してください**

### 1-4. テストユーザーの登録

1. 関数選択で `testRegisterUsers` を選択
2. 実行ボタンをクリック
3. 実行ログで「テストユーザー登録完了」を確認

### 1-5. スプレッドシートの確認

1. 保存したスプレッドシートURLにアクセス
2. 「Users」シートと「MainDB」シートが作成されていることを確認
3. Usersシートにテストユーザーが登録されていることを確認

### 1-6. Webアプリとしてデプロイ

1. エディタ右上の「デプロイ」→「新しいデプロイ」をクリック
2. 「種類の選択」で歯車アイコンをクリック → 「ウェブアプリ」を選択
3. 設定：
   ```
   説明: 社労士ゲームAPI v1
   次のユーザーとして実行: 自分（your-email@gmail.com）
   アクセスできるユーザー: 全員
   ```
4. 「デプロイ」をクリック
5. **ウェブアプリのURLをコピー**（重要！）
   - 例: `https://script.google.com/macros/s/AKfycby.../exec`
   - このURLを次のステップで使用します

## 🌐 ステップ2: フロントエンドのデプロイ

### 2-1. API URLの設定

1. `frontend/app.js` を開く
2. 6行目の `API_URL` を先ほどコピーしたURLに変更：

```javascript
const API_URL = 'https://script.google.com/macros/s/YOUR_ACTUAL_DEPLOYMENT_ID/exec';
```

3. `frontend/admin.js` も同様に更新（6行目）

### 2-2. ホスティングサービスの選択

#### オプション A: GitHub Pages（推奨）

1. GitHubリポジトリを作成
2. `frontend/` フォルダの内容をリポジトリにプッシュ
3. Settings → Pages → Source を `main` ブランチに設定
4. 公開URLを確認（例: `https://username.github.io/sr-game/`）

#### オプション B: Netlify

1. https://www.netlify.com にサインアップ
2. 「Add new site」→「Deploy manually」
3. `frontend/` フォルダをドラッグ&ドロップ
4. 公開URLを確認

#### オプション C: Vercel

1. https://vercel.com にサインアップ
2. 「New Project」をクリック
3. `frontend/` フォルダをインポート
4. デプロイを実行

### 2-3. HTTPS の確認

音声認識（Web Speech API）はHTTPSまたはlocalhostでのみ動作します。
上記のホスティングサービスはすべて自動的にHTTPSを提供します。

## 🔍 ステップ3: 動作確認

### 3-1. 基本動作のテスト

1. デプロイしたURLにアクセス
2. プレイヤー選択画面でテストユーザーが表示されることを確認
3. ユーザーを選択して「次へ」
4. 業界を選択して「次へ」
5. マイクボタンをタップ：
   - ブラウザがマイクの使用許可を求めます → 「許可」をクリック
   - 録音インジケーターが赤くなることを確認
   - 何か話してみる → 文字起こしが表示されることを確認
6. マイクボタンを再度タップして録音停止
7. 「送信」をクリック
8. 完了画面が表示されることを確認

### 3-2. データ保存の確認

1. Google Sheetsのスプレッドシートを開く
2. 「MainDB」シートを確認
3. 送信したデータが保存されていることを確認

### 3-3. 管理者画面のテスト

1. `https://your-deployed-url/admin.html` にアクセス
2. ユーザー一覧が表示されることを確認
3. 新規ユーザーを登録してみる
4. ユーザー一覧が更新されることを確認

## 🔧 トラブルシューティング

### エラー: 「アクセスが拒否されました」

- Google Apps Scriptのデプロイ設定を確認
- 「アクセスできるユーザー」が「全員」になっているか確認
- デプロイURLが正しいか確認

### エラー: 「音声認識が動作しない」

- HTTPSでアクセスしているか確認
- ブラウザがChrome、Edge、Safariか確認
- マイクの使用許可を与えているか確認

### エラー: 「ユーザーが表示されない」

- Google Apps Scriptで `initializeSpreadsheet()` を実行したか確認
- `testRegisterUsers()` を実行したか確認
- API URLが正しく設定されているか確認

### エラー: 「データが保存されない」

- ブラウザのコンソール（F12）でエラーメッセージを確認
- Google Apps Scriptのログでエラーがないか確認
- API URLが正しいか再確認

## 🔄 更新手順

### Google Apps Scriptの更新

1. `backend/Code.gs` を編集
2. Google Apps Script エディタにコピー
3. 「デプロイ」→「デプロイを管理」をクリック
4. 既存のデプロイの鉛筆アイコンをクリック
5. 「バージョン」→「新バージョン」を選択
6. 「デプロイ」をクリック

**注意**: URLは変更されないので、フロントエンドの更新は不要です。

### フロントエンドの更新

1. `frontend/` のファイルを編集
2. ホスティングサービスに再デプロイ：
   - **GitHub Pages**: git push
   - **Netlify**: 新しいファイルをドラッグ&ドロップ
   - **Vercel**: git push またはCLIでデプロイ

## 🔐 セキュリティ考慮事項

### 管理者画面のアクセス制限

現在の実装では管理者画面は誰でもアクセスできます。
本番環境では以下のいずれかの方法でアクセス制限を推奨：

1. **ベーシック認証**（Netlify、Vercelで設定可能）
2. **IPアドレス制限**
3. **Google Apps Scriptでの認証実装**

### スプレッドシートのアクセス権限

- スプレッドシートの共有設定を確認
- 必要な人だけに編集権限を付与
- 閲覧専用の共有リンクは作成しない

## 📊 運用のベストプラクティス

### 定期的なバックアップ

1. Google Sheetsの「ファイル」→「コピーを作成」で定期的にバックアップ
2. または Google Apps Scriptで自動バックアップを実装

### パフォーマンスモニタリング

- Google Apps Scriptの実行ログを定期的に確認
- エラーが発生していないかチェック

### データのエクスポート

必要に応じてスプレッドシートからCSVでエクスポート可能：
1. スプレッドシートを開く
2. 「ファイル」→「ダウンロード」→「カンマ区切り形式（.csv）」

## 🎉 デプロイ完了！

すべてのステップが完了したら、本番環境での運用を開始できます。
