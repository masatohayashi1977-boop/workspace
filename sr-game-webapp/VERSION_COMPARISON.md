# バージョン比較ガイド

社労士ゲームWEBアプリには2つのバージョンがあります。用途に応じて選択してください。

## 📦 2つのバージョン

### 1. GAS統合版（推奨）
**すべてがGoogle Apps Script内で完結**

📁 ディレクトリ: `gas-integrated/`

### 2. 分離版
**フロントエンドとバックエンドを分離**

📁 ディレクトリ: `frontend/` + `backend/`

---

## 🆚 詳細比較

| 項目 | GAS統合版 ⭐推奨 | 分離版 |
|------|----------------|--------|
| **セットアップの簡単さ** | ⭐⭐⭐<br>GASだけで完結<br>5分で完了 | ⭐⭐<br>GAS + ホスティングサービス<br>10-15分必要 |
| **必要な知識** | GASの基本操作のみ | GAS + Git/デプロイ |
| **管理のしやすさ** | ⭐⭐⭐<br>1箇所で一括管理 | ⭐⭐<br>2箇所の管理が必要 |
| **コードの更新** | GASエディタで直接編集<br>即座に反映 | フロント・バック別々に更新 |
| **パフォーマンス** | ⭐⭐<br>GAS経由でやや遅い<br>（通常は問題なし） | ⭐⭐⭐<br>静的ホスティングで高速 |
| **URL** | GASの自動URL<br>`script.google.com/...` | カスタムドメイン可能<br>`your-domain.com` |

| **カスタマイズ性** | ⭐⭐<br>GASの制限内 | ⭐⭐⭐<br>自由度高い |
| **モバイル対応** | ⭐⭐⭐<br>完全対応 | ⭐⭐⭐<br>完全対応 |

## 🔄 移行について

### GAS統合版 → 分離版への移行

データベース（Google Sheets）は共通なので、フロントエンドを別ホスティングに移すだけ：

1. `frontend/`フォルダの内容をホスティングサービスにデプロイ
2. `app.js`と`admin.js`のAPI URLを設定
3. GASのデプロイURLはそのまま使用可能

### 分離版 → GAS統合版への移行

1. `gas-integrated/`の3ファイルをGASにコピー
2. 既存のスプレッドシートIDはそのまま使用可能
3. 新しくデプロイしてURLを置き換え

**どちらの方向も簡単に移行できます。**
