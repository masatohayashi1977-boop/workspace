# 社労士ゲーム WEBアプリ（GAS統合版）

**すべてがGoogle Apps Script内で完結するバージョン**

このバージョンでは、フロントエンド（HTML/CSS/JavaScript）とバックエンド（Google Apps Script）がすべてGAS内に統合されています。

## 🎯 統合版の特徴

### ✅ メリット
- **超簡単セットアップ**: GASだけで完結、外部ホスティング不要
- **API設定不要**: URLの書き換えなし、`google.script.run`で直接呼び出し
- **1箇所で管理**: コードの更新も1箇所のみ
- **完全無料**: Google Appsの無料枠で運用可能
- **CORS問題なし**: 同一ドメインなので制限なし

### ⚠️ デメリット
- **GASのURLを使用**: カスタムドメイン不可
- **やや低速**: GAS経由のため、静的ホスティングより遅い
- **GASの制限**: 実行時間やクォータの制限あり

gas-integrated/

## 🚀 セットアップ手順

### 1. Google Apps Scriptプロジェクトの作成

1. https://script.google.com にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「社労士ゲーム」に変更

### 2. ファイルのアップロード

#### 2-1. Code.gs の作成

1. デフォルトで作成される `Code.gs` を開く
2. `gas-integrated/Code.gs` の内容を全選択してコピー
3. GASエディタに貼り付け
4. 保存（Ctrl+S / Cmd+S）

#### 2-2. Index.html の作成

1. 左メニューの「ファイル」の横にある「+」をクリック
2. 「HTML」を選択
3. ファイル名を「Index」に変更
4. `gas-integrated/Index.html` の内容を全選択してコピー
5. GASエディタに貼り付け
6. 保存

#### 2-3. Admin.html の作成

1. 同様に「+」→「HTML」をクリック
2. ファイル名を「Admin」に変更
3. `gas-integrated/Admin.html` の内容をコピー&ペースト
4. 保存

**最終的なファイル構成:**
```
社労士ゲーム (GASプロジェクト)
├── Code.gs
├── Index.html
└── Admin.html
```

### 3. スプレッドシートの初期化

1. GASエディタ上部の関数選択ドロップダウンをクリック
2. `initializeSpreadsheet` を選択
3. 実行ボタン（▶️）をクリック
4. 初回実行時：
   - 「承認が必要です」→「権限を確認」をクリック
   - Googleアカウントを選択
   - 「詳細」→「（安全ではないページ）に移動」をクリック
   - 「許可」をクリック
5. 再度実行ボタンをクリック
6. 「実行ログ」タブでスプレッドシートURLを確認
   - `新規スプレッドシート作成: https://docs.google.com/spreadsheets/d/...`
   - **このURLを保存してください**（後でデータを見る際に使います）

### 4. テストユーザーの登録

1. 関数選択で `testRegisterUsers` を選択
2. 実行ボタンをクリック
3. 実行ログで「テストユーザー登録完了」を確認

### 5. Webアプリとしてデプロイ

1. 右上の「デプロイ」→「新しいデプロイ」をクリック
2. 「種類の選択」（歯車アイコン⚙️）をクリック
3. 「ウェブアプリ」を選択
4. 設定：
   ```
   説明: 社労士ゲーム v1
   次のユーザーとして実行: 自分
   アクセスできるユーザー: 全員
   ```
5. 「デプロイ」をクリック
6. **ウェブアプリのURLをコピー**
   - 例: `https://script.google.com/macros/s/AKfycby.../exec`
   - このURLがアプリのアドレスになります

## 🎮 使い方

### メインゲーム画面

デプロイしたURLにアクセス：
```
https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
```

### 管理者画面

URLに `?page=admin` を追加：
```
https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec?page=admin
```

または、メインゲーム画面右上の「⚙️ 管理」リンクをクリック

## 📱 動作確認

### 1. メインゲーム画面のテスト

1. デプロイURLにアクセス
2. プレイヤー選択でテストユーザーが表示されることを確認
3. ユーザーを選択 → 業界を選択
4. マイクボタンをタップ（マイクの許可を求められたら「許可」）
5. 何か話して文字起こしを確認
6. 送信して完了画面が表示されることを確認

### 2. 管理者画面のテスト

1. `?page=admin` にアクセス
2. ユーザー一覧が表示されることを確認
3. 新規ユーザーを登録してみる
4. 「スプレッドシートを開く」ボタンをクリックしてデータを確認

### 3. データ保存の確認

1. スプレッドシートを開く
2. 「MainDB」シートに送信したデータが保存されていることを確認

## 🔄 コードの更新方法

### 更新手順

1. GASエディタで該当ファイルを編集
2. 保存（Ctrl+S / Cmd+S）
3. 「デプロイ」→「デプロイを管理」をクリック
4. 既存のデプロイの鉛筆アイコン（✏️）をクリック
5. 「バージョン」→「新バージョン」を選択
6. 「デプロイ」をクリック

**重要**: URLは変わりません。既存のURLでアクセスすると更新後のコードが実行されます。

## 🔧 トラブルシューティング

### エラー: 「スプレッドシートが初期化されていません」

→ `initializeSpreadsheet()` 関数を実行してください

### エラー: 「ユーザーが表示されない」

→ `testRegisterUsers()` 関数を実行してテストユーザーを登録してください

### エラー: 「音声認識が動作しない」

→ 対応ブラウザ（Chrome、Edge、Safari）を使用してください
→ マイクの使用許可を与えてください
→ HTTPSでアクセスしてください（GASのURLは自動的にHTTPS）

### エラー: 「データが保存されない」

→ ブラウザのコンソール（F12）でエラーを確認
→ GASの実行ログでエラーがないかチェック
→ スプレッドシートの権限を確認

### 画面が真っ白になる

→ GASエディタで「実行ログ」を確認
→ HTMLファイルの構文エラーがないか確認
→ ブラウザのキャッシュをクリア

### スプレッドシートの確認方法

1. GASエディタで以下の関数を実行：
   ```javascript
   function showSpreadsheetUrl() {
     const url = getSpreadsheetUrl();
     Logger.log(url);
   }
   ```
2. 実行ログに表示されるURLをクリック

または：

1. 管理者画面（`?page=admin`）にアクセス
2. 「スプレッドシートを開く」ボタンをクリック

### バックアップ

1. スプレッドシートを開く
2. 「ファイル」→「コピーを作成」で定期的にバックアップ

### データのエクスポート

1. スプレッドシートを開く
2. 「ファイル」→「ダウンロード」→「カンマ区切り形式（.csv）」

## 🔒 セキュリティ

### 管理者画面のアクセス制限

現在は誰でもアクセスできます。制限する場合：

1. **Session.getActiveUser()を使用**
   ```javascript
   function doGet(e) {
     const user = Session.getActiveUser().getEmail();
     const allowedUsers = ['admin@example.com'];

     if (e.parameter.page === 'admin' && !allowedUsers.includes(user)) {
       return HtmlService.createHtmlOutput('アクセス権限がありません');
     }
     // ...
   }
   ```

2. **パスワード認証を追加**
   - Properties Serviceにパスワードを保存
   - 管理画面にログインフォームを追加

## 💡 よくある質問

**Q: スマホでも動きますか？**
A: はい、スマホ・タブレット対応のレスポンシブデザインです。

**Q: 何人まで同時にアクセスできますか？**
A: GASの同時実行数制限（通常30）まで可能です。

**Q: データの保存容量は？**
A: Google Sheetsの制限（500万セル、約400MB）まで使用可能です。

**Q: 独自ドメインは使えますか？**
A: いいえ。独自ドメインが必要な場合は分離版を使用してください。

**Q: オフラインで使えますか？**
A: いいえ。インターネット接続が必要です。
