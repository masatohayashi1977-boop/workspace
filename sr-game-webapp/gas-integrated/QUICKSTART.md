# クイックスタートガイド

最短5分でセットアップ！

## ステップ1: GASプロジェクト作成（30秒）

1. https://script.google.com を開く
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「社労士ゲーム」に変更

## ステップ2: コードをコピー＆ペースト（2分）

### Code.gs
1. デフォルトの`Code.gs`を開く
2. `gas-integrated/Code.gs`の内容を**全選択してコピー**
3. GASエディタに**貼り付け**
4. 保存（Ctrl+S）

### Index.html
1. 左の「+」→「HTML」をクリック
2. 名前を`Index`に変更
3. `gas-integrated/Index.html`の内容を**コピー&ペースト**
4. 保存

### Admin.html
1. 左の「+」→「HTML」をクリック
2. 名前を`Admin`に変更
3. `gas-integrated/Admin.html`の内容を**コピー&ペースト**
4. 保存

## ステップ3: 初期化（1分）

1. 上部の関数選択で`initializeSpreadsheet`を選択
2. 実行ボタン（▶️）をクリック
3. **初回のみ**: 「承認が必要」→「権限を確認」→「許可」
4. 再度実行ボタンをクリック
5. **実行ログのURL**をメモ（スプレッドシートのURL）

## ステップ4: テストユーザー登録（30秒）

1. 関数選択で`testRegisterUsers`を選択
2. 実行ボタンをクリック
3. ログに「テストユーザー登録完了」と表示されればOK

## ステップ5: デプロイ（1分）

1. 右上「デプロイ」→「新しいデプロイ」
2. 歯車アイコン（⚙️）→「ウェブアプリ」を選択
3. 設定：
   - 実行: **自分**
   - アクセス: **全員**
4. 「デプロイ」をクリック
5. **ウェブアプリのURL**をコピー

## ✅ 完了！

### アクセス方法

**メインゲーム:**
```
https://script.google.com/macros/s/YOUR_ID/exec
```

**管理画面:**
```
https://script.google.com/macros/s/YOUR_ID/exec?page=admin
```

## 🎮 動作テスト

1. ゲーム画面を開く
2. プレイヤーを選択
3. 業界を選択
4. マイクボタンをタップ
5. 何か話す
6. 送信

管理画面から「スプレッドシートを開く」をクリック
