# タイムトラッキングアプリ AI評価フィードバックシステム

Google Apps ScriptとGemini 2.5 Flashを使用した、業務データの自動フィードバック配信システムです。毎日8:00に前日の業務データを分析し、個人向けと管理者向けのフィードバックメールを自動送信します。

## 特徴

### 🎯 個人向けフィードバック
- **AIによる励ましのコメント**: Gemini 2.5が業務内容を分析し、ポジティブなフィードバックを提供
- **詳細な業務サマリー**: 稼働時間、タスク数、最長タスクを表示
- **タスク一覧**: 顧客、種別、目標、所感を含む全タスクの詳細
- **美しいデザイン**: グラデーション背景とカラフルなレイアウト

### 📊 管理者向けレポート
- **チーム全体の分析**: AIによるマネジメント視点の分析
- **統計ダッシュボード**: 対象メンバー数、総稼働時間、総タスク数、平均値
- **メンバー別詳細**: 稼働時間、タスク数、平均タスク時間
- **改善提案**: チームの生産性向上のための具体的なアドバイス

## システム要件

- Google Workspace アカウント
- Google Spreadsheet（業務データ管理用）
- Gemini API キー（Google AI Studio で取得）
- Gmail（メール送信用）

## セットアップ

### 1. スプレッドシートの準備

以下の4つのシートを作成してください：

#### 「集計」シート
業務実績データを記録するシートです。

| カラム名 | 説明 | 例 |
|---------|------|-----|
| 年月日 | 業務日付 | 2025-11-03 |
| 氏名 | ユーザーID（重要！） | a001 |
| 種別 | 作業種別のID | t001 |
| 顧客 | 顧客のID | c001 |
| 業務内容 | タスクの内容 | 提案書作成 |
| 目標 | タスクの目標 | 明日までに完成 |
| 開始時間 | 開始時刻 | 09:00 |
| 終了時間 | 終了時刻 | 10:30 |
| 所要時間 | 所要時間（時刻形式または数値） | 1:30 または 1.5 |
| 所感 | 業務の所感 | スムーズに進んだ |
| 完了 | 完了フラグ | TRUE/FALSE |

**重要**: 「氏名」カラムには、ユーザーの名前ではなく**ユーザーID**（a001など）を入力してください。

#### 「ユーザー管理」シート

| カラム名 | 説明 | 例 |
|---------|------|-----|
| ID | ユーザーID | a001 |
| 氏名 | ユーザーの実名 | 林 真人 |
| メールアドレス | フィードバック送信先 | user@example.com |

#### 「種別」シート

| カラム名 | 説明 | 例 |
|---------|------|-----|
| ID | 種別ID | t001 |
| 種別 | 作業種別名 | ミーティング |

#### 「顧客」シート

| カラム名 | 説明 | 例 |
|---------|------|-----|
| ID | 顧客ID | c001 |
| 顧客名 | 顧客名 | ABC株式会社 |

### 2. Gemini APIキーの取得

1. [Google AI Studio](https://aistudio.google.com/app/apikey) にアクセス
2. 「API キーを取得」をクリック
3. 新しいAPIキーを作成
4. APIキーをコピー（後で使用）

### 3. Google Apps Scriptのセットアップ

1. スプレッドシートを開く
2. メニューから「拡張機能」→「Apps Script」を選択
3. 既存のコードを削除
4. `ai-feedback-system.gs` の内容を貼り付け
5. 設定を変更：

```javascript
const CONFIG = {
  GEMINI_API_KEY: 'YOUR_API_KEY_HERE',  // ここに取得したAPIキーを貼り付け
  SHEET_NAME: {
    aggregation: '集計',
    users: 'ユーザー管理',
    types: '種別',
    customers: '顧客'
  },
  ADMIN_EMAIL: 'admin@example.com',  // 管理者のメールアドレス
  FEEDBACK_TIME: 8  // フィードバック送信時刻（8:00）
};
```

6. 「保存」ボタンをクリック

### 4. 権限の承認

初回実行時に権限の承認が必要です：

1. スクリプトエディタで関数を選択（例：`testDataRetrieval`）
2. 「実行」ボタンをクリック
3. 「権限を確認」をクリック
4. Googleアカウントを選択
5. 「詳細」→「（プロジェクト名）に移動」をクリック
6. 「許可」をクリック

## 使用方法

### テスト実行

本番運用前に、以下のテスト関数で動作確認してください：

#### 1. データ取得テスト
```javascript
testDataRetrieval()
```
- スプレッドシートからデータが正しく取得できるか確認
- ログで各マスターデータの件数を確認

#### 2. ユーザーマスター詳細確認
```javascript
testUserMaster()
```
- ユーザー管理シートの内容を詳細確認
- IDとメールアドレスが正しく取得できているか確認

#### 3. 今日のデータでテスト（メール送信なし）
```javascript
testFeedbackToday()
```
- 今日のデータでAI評価まで実行
- メール送信はコメントアウトされているので安全

#### 4. 前日データで完全テスト（メール送信あり）
```javascript
testFeedback()
```
- 前日のデータで完全に実行
- **実際にメールが送信されます**のでご注意ください

### トリガー設定（自動実行）

毎日8:00に自動実行するには：

#### 方法1: 関数を使用（推奨）
```javascript
setupDailyTrigger()
```
この関数を1回実行するだけで、毎日8:00の自動実行が設定されます。

#### 方法2: 手動設定
1. スクリプトエディタで「トリガー」アイコン（時計マーク）をクリック
2. 「トリガーを追加」をクリック
3. 以下のように設定：
   - 実行する関数: `sendDailyFeedback`
   - イベントのソース: `時間主導型`
   - 時間ベースのトリガー: `日付ベースのタイマー`
   - 時刻: `午前8時～午前9時`
4. 「保存」をクリック

### トリガーの削除

自動実行を停止するには：
```javascript
deleteDailyTrigger()
```

## 動作フロー

```
毎日 8:00
    ↓
前日のデータを取得
    ↓
ユーザーごとにグループ化
    ↓
各ユーザーの業務データをGemini 2.5で分析
    ↓
個人向けメール送信（各ユーザーへ）
    ↓
チーム全体をGemini 2.5で分析
    ↓
管理者向けレポート送信
```

## トラブルシューティング

### メールが届かない

**症状**: フィードバックメールが送信されない

**確認事項**:
1. ログを確認：「表示」→「ログ」
2. エラーメッセージをチェック

**よくある原因**:
- ユーザー管理シートにメールアドレスが登録されていない
- 「集計」シートの「氏名」列とユーザー管理シートの「ID」列が一致していない
- 前日のデータが存在しない

### ユーザーIDの照合エラー

**エラーメッセージ**:
```
ユーザー a001 のメールアドレスが見つかりません
```

**原因**:
集計シートの「氏名」列の値（例：a001）がユーザー管理シートの「ID」列に存在しない

**解決方法**:
1. `testUserMaster()` を実行してユーザー管理シートの内容を確認
2. 集計シートの「氏名」列の値とユーザー管理シートの「ID」列の値が完全一致するか確認

### Gemini APIエラー

**エラーメッセージ**:
```
フィードバック生成に失敗しました
```

**確認事項**:
1. APIキーが正しいか確認
2. Gemini APIの利用制限に達していないか確認
3. ログで詳細なエラーメッセージを確認

**よくある原因**:
- APIキーが無効または期限切れ
- APIの無料枠を使い切った
- ネットワークエラー

### MAX_TOKENSエラー

**エラーメッセージ**:
```
警告: トークン数上限に達しました
```

**原因**:
タスク数が多すぎてプロンプトが長くなり、Geminiの出力トークン数が不足

**解決方法**:
1. `maxOutputTokens` を増やす（現在2048）
2. プロンプトを簡潔にする
3. タスク数を制限する

### 所要時間が正しく計算されない

**確認事項**:
1. 集計シートの「所要時間」列のフォーマット
2. ログで所要時間の値を確認

**対応フォーマット**:
- 数値: `1.5` (1.5時間)
- 文字列: `"1.5"` (1.5時間)
- 時刻形式: `"1:30"` (1時間30分)
- Date型: Googleスプレッドシートの時刻型

## セキュリティ上の注意

### APIキーの管理

**重要**: APIキーは公開しないでください。

より安全な管理方法：

1. スクリプトプロパティに保存：

```javascript
// 初回のみ実行（APIキーを保存）
function saveApiKey() {
  PropertiesService.getScriptProperties().setProperty('GEMINI_API_KEY', 'YOUR_API_KEY_HERE');
}

// CONFIG内で取得
const CONFIG = {
  GEMINI_API_KEY: PropertiesService.getScriptProperties().getProperty('GEMINI_API_KEY'),
  // ...
};
```

2. Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」で直接設定

### メールアドレスの確認

誤送信を防ぐため、テスト実行時は：
1. 最初は自分のメールアドレスのみで確認
2. 内容を確認してから本番運用開始

## 技術仕様

### 使用技術
- **Google Apps Script**: スクリプト実行環境
- **Gemini 2.5 Flash**: AI分析エンジン
- **Gmail API**: メール送信
- **Spreadsheet API**: データ取得

### APIパラメータ

```javascript
generationConfig: {
  temperature: 0.7,        // 創造性のバランス
  maxOutputTokens: 2048,   // 最大出力トークン数
  topP: 0.9,              // 核サンプリング
  topK: 40,               // トップKサンプリング
  responseMimeType: 'text/plain'
}
```

### データ処理
- 日付比較: YYYY-MM-DD形式に統一
- 所要時間: Date型、数値、文字列（HH:MM）に対応
- ユーザー照合: ユーザーIDベース
