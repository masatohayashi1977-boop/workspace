# NexusHub タイムトラッキングシステム

Google Apps Scriptベースのタイムトラッキング・勤怠管理システムです。

## 機能

### 個人用アプリ (Index.html)
- ⏱️ **タイムトラッキング**: 作業時間の開始・停止
- 📊 **サマリー表示**: 今日・今週の作業時間を可視化
- 📝 **作業履歴**: プロジェクト・タスク別の作業記録
- ✏️ **編集機能**: 作業エントリーの編集・削除

### 管理者用ダッシュボード (Admin.html)
- 👥 **ユーザー別サマリー**: 全員の作業時間を一覧表示
- 📈 **統計情報**: 総作業時間、アクティブユーザー数など
- 📋 **エントリー一覧**: 全ての作業記録を表形式で表示
- 📥 **データエクスポート**: CSV形式でデータをダウンロード
- 🔍 **期間フィルター**: 日付・期間での絞り込み

## セットアップ手順

### 1. Google Apps Scriptプロジェクトの作成

1. [Google Apps Script](https://script.google.com)にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「NexusHub Time Tracking」に変更

### 2. ファイルのアップロード

以下のファイルをGoogle Apps Scriptプロジェクトに追加します：

#### Code.gs
1. デフォルトの`Code.gs`を開く
2. 提供された`Code.gs`の内容をコピー&ペースト

#### Index.html (個人用UI)
1. 「+」ボタンから「HTML」を選択
2. ファイル名を`Index`に変更
3. 提供された`Index.html`の内容をコピー&ペースト

#### Admin.html (管理者用UI)
1. 「+」ボタンから「HTML」を選択
2. ファイル名を`Admin`に変更
3. 提供された`Admin.html`の内容をコピー&ペースト

### 3. デプロイ

1. 「デプロイ」→「新しいデプロイ」をクリック
2. 「種類の選択」で「ウェブアプリ」を選択
3. 設定:
   - **説明**: NexusHub Time Tracking
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 組織内の全員（またはドメイン内の全員）
4. 「デプロイ」をクリック
5. 権限の承認を求められたら、承認

### 4. URLの取得

デプロイ後、2つのURLが必要です：

- **個人用アプリ**: `https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec`
- **管理者用ダッシュボード**: `https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec?page=admin`

## 使い方

### 個人用アプリ

#### タイムトラッキングの開始
1. 「開始」ボタンをクリック
2. プロジェクト、タスク、メモを入力（任意）
3. 「開始」をクリック

#### タイムトラッキングの停止
1. 作業中に「停止」ボタンをクリック
2. 自動的に作業時間が記録されます

#### 作業履歴の確認
- 日付フィルターで期間を指定
- エントリーの編集・削除が可能

### 管理者用ダッシュボード

#### ユーザー別サマリーの確認
1. URLに`?page=admin`を追加してアクセス
2. 期間フィルターで絞り込み
3. ユーザー別の作業時間とプロジェクト内訳を確認

#### データのエクスポート
1. 期間フィルターで絞り込み
2. 「エクスポート」ボタンをクリック
3. CSV形式でダウンロード

## プロジェクト管理

### プロジェクトの追加

プロジェクトを追加するには、Google Apps Scriptのエディタで以下の関数を実行します：

```javascript
function addSampleProject() {
  addProject('プロジェクトA', 'プロジェクトAの説明');
}
```

または、直接スプレッドシートの「Projects」シートに追加します。

## データ保存

データは自動的に作成されるGoogle Spreadsheetに保存されます：

- **TimeEntries**: タイムエントリー（作業記録）
- **Projects**: プロジェクト一覧

スプレッドシートのURLは、初回実行時にログに出力されます。

## カスタマイズ

### タイムゾーンの変更
`appsscript.json`の`timeZone`を変更します：

```json
{
  "timeZone": "Asia/Tokyo"
}
```

### アクセス権限の変更
`appsscript.json`の`access`を変更します：

- `DOMAIN`: ドメイン内の全員
- `ANYONE`: 誰でもアクセス可能
- `ANYONE_ANONYMOUS`: 匿名アクセス可能

## トラブルシューティング

### スプレッドシートが作成されない
1. Google Apps Scriptのログを確認
2. スプレッドシートの作成権限があることを確認

### データが表示されない
1. ブラウザのコンソールでエラーを確認
2. Google Apps Scriptの実行ログを確認
3. キャッシュをクリアして再読み込み

### 権限エラー
1. デプロイ時の権限承認を再度実行
2. Google Workspaceの管理者に確認

## セキュリティ

- データは組織のGoogle Driveに保存されます
- アクセスはGoogle Workspaceの認証で制御されます
- ユーザーは自分のデータのみ編集可能（閲覧は管理者のみ全体を確認可能）

## サポート

問題が発生した場合は、以下を確認してください：

1. Google Apps Scriptの実行ログ
2. ブラウザのコンソールログ
3. スプレッドシートのデータ
